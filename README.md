Política de Privacidad – REBT Experto Última actualización: 2026 REBT Experto es una aplicación de consulta técnica diseñada para profesionales del sector eléctrico. 1. Información que recopilamos La aplicación no solicita registro de usuario ni recopila datos personales identificables como nombre, dirección o información de pago. Cuando el usuario realiza una consulta técnica, el texto introducido se envía a un servidor seguro para generar una respuesta. Estas consultas pueden procesarse temporalmente con multas exclusivamente técnicas y de funcionamiento del servicio. No se recopilan datos sensibles. 2. Uso de la información La información enviada en las consultas se utiliza únicamente para: Generar respuestas técnicas. Mejorar el funcionamiento del servicio. No vendemos ni compartimos información con terceros. 3. Servicios de terceros La aplicación utiliza servicios externos de procesamiento de lenguaje natural para generar respuestas técnicas. Estos servicios pueden procesar temporalmente el contenido de las consultas con finos operativos. 4. Seguridad Se aplican medidas técnicas razonables para proteger la información transmitida. 5. Público objetivo La aplicación está dirigida a usuarios mayores de 18 años. 6. Contacto Si tienes preguntas sobre esta política, puedes contactar en: jimenezaugusto49@gmail.com
