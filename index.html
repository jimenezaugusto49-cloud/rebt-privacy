Política de Privacidad – REBT Experto

Última actualización: Noviembre de 2026

REBT Experto es una aplicación de consulta técnica y generación de documentación diseñada para profesionales del sector eléctrico.

1. Información que recopilamos

Para ofrecer las funciones avanzadas de la aplicación, recopilamos y procesamos los siguientes tipos de información:

  • Información personal para MTD Express (Opcional): Cuando utilizas el formulario MTD Express para redactar o generar documentos en formato PDF, la aplicación transmite temporalmente datos identificativos como nombre, dirección, número de teléfono, DNI/NIE y datos de instalaciones. Estos datos los proporciona voluntariamente el usuario en el momento de generar el documento.
  • Consultas del chat (Contenido generado por el usuario): Las consultas técnicas escritas en el chat se envían a nuestros servidores para generar las respuestas correspondientes.
  • Almacenamiento local en el dispositivo: El historial del chat y los archivos PDF generados se guardan localmente en la memoria o caché de tu propio dispositivo.

No recopilamos información de ubicación, contactos, datos financieros ni identificadores publicitarios.

2. Uso de la información

La información recopilada se utiliza exclusivamente para:

  • Habilitar las funciones principales de la app (generación de documentos PDF y asistencia técnica del chat).
  • Mantener la operatividad del servicio.

No vendemos, alquilamos ni comercializamos tus datos personales con terceros.

3. Servicios y proveedores de terceros

Para llevar a cabo el procesamiento de datos, utilizamos proveedores de infraestructura y servicios de computación que actúan bajo nuestras instrucciones como encargados del tratamiento:

  • Infraestructura en la nube (Render): Los datos transmitidos desde MTD Express se procesan de forma temporal en nuestro backend alojado en Render para compilar y entregar los documentos solicitados.
  • Procesamiento de Lenguaje Natural (OpenAI API): Las consultas técnicas enviadas a través del chat son procesadas por la API de OpenAI para generar las respuestas. OpenAI conserva los registros de solicitudes y respuestas de la API por motivos de prevención de abusos durante un plazo máximo de 30 días, y no utiliza estos datos para entrenar sus modelos de lenguaje.

4. Retención de datos y eliminación

Los datos personales introducidos en MTD Express se procesan durante el tiempo estrictamente necesario para generar y devolver el archivo PDF al usuario.

Si deseas solicitar la eliminación de cualquier información residual o realizar una consulta sobre tus datos, puedes enviar una solicitud a la dirección de contacto indicada más abajo.

5. Cifrado y seguridad

Toda la información transmitida entre la aplicación, el servidor y los servicios de terceros se realiza mediante conexiones HTTPS cifradas en tránsito (TLS/SSL).

6. Público objetivo

La aplicación está dirigida a profesionales y usuarios mayores de 18 años.
